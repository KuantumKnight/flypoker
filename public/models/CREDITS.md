# Fly Poker model credits

## Spy Fly

- **Model:** Spy Fly, by **sunburn**
- **Source:** https://opengameart.org/content/spy-fly
- **License:** Creative Commons Attribution 3.0 (CC BY 3.0)
- **Use in this project:** the source fly mesh is converted to `spyfly.glb` for the WebGL table. The original mesh is unrigged; Fly Poker adds insect-only forelegs for card and chip handling and keeps the body silhouette 100% fly.
- **Runtime SHA-256:** `E222B1F0D1E4E8F9C629D498DD5DFDDF359F034A4B440A9CC761FC8CC208B2B7`

## Poker table

- **Pack:** Poker Pack, by **mehrasaur**
- **Source:** https://opengameart.org/content/poker-pack
- **License:** CC0 1.0 (public domain)
- **Use in this project:** `table.obj`/`table.mtl`, `card.obj`/`card.mtl`, and `chip_25.obj`/`chip_25.mtl` provide the physical table, card, and chip meshes. Labels, card values, and chip counts remain event-driven overlays so recorded hands stay deterministic.

The downloaded source archives are intentionally not served to browsers. Only the optimized runtime assets in this directory are shipped.
