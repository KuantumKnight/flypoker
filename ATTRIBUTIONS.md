# Fly Poker attributions

Fly Poker is an entertainment and portfolio project. The following external
work is used with attribution:

- **fly.ai / FlyBrain** — the open-source Python implementation of the
  MaleCNS leaky-integrate-and-fire network:
  <https://github.com/alextitonis/fly.ai>
- **MaleCNS v1.0** — public connectome data consumed by FlyBrain. The checked
  `fly-data/` files are identified by the SHA-256 hash recorded in
  `artifacts/readout-male-cns-gpu/manifest.json`.
- **PokerKit** — authoritative Hold'em rules, betting legality, side pots,
  and showdown resolution:
  <https://pokerkit.readthedocs.io/en/stable/reference.html>
- **Spy Fly** by sunburn — CC BY 3.0 fly mesh used in the WebGL scene:
  <https://opengameart.org/content/spy-fly>
- **Poker Pack** by mehrasaur — CC0 table mesh used in the WebGL scene:
  <https://opengameart.org/content/poker-pack>

The connectome and LIF simulation are the scientific source material. Poker
feature encoding, teacher labels, PCA, linear readouts, personality variants,
camera choreography, and commentary are engineered by this project. Nothing
here is evidence that biological flies understand poker.
